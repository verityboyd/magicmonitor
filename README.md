# Magic Monitor

## To all who come to this wait time tracker... welcome!

## Web Development 2 Final Project

## By Verity Boyd

This is my final project for the SAIT CPRG-306 web development 2 course. It is a React project designed to allow visitors to view and track the queue wait times of their favourite Disney Park rides across the globe.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- shadcn/ui
- Firebase & Firestore
- Custom API hooks - thank you to queue-times.com for providing the data.
- Context API

## Main Features

- Real-time ride wait times per park
- User authentication
- Favourite rides stored site-wide
- Notifications when a ride drops below a user-defined wait time threshold
- Park pages with lands and rides per park
- Sort rides within lands with wait time lowest to highest and vice-versa
- Filter between all rides, all open rides, or all closed rides
- Responsive UI

## Getting Started

- run npm install
- run npm run dev
