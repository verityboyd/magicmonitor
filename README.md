# Magic Monitor

## To all who come to this wait time tracker... welcome!

## Web Development 2 Final Project

## By Verity Boyd

This is my final project for the SAIT CPRG-306 web development 2 course. It is a React project designed to allow visitors to view and track the queue wait times of their favourite Disney Park rides across the globe.
